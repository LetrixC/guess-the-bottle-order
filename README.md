# Guess the Bottle Order · 9 Dots Consulting

An 8-bit, Mastermind-style logic game in 9 Dots blue, white and black.

**Play:** https://letrixc.github.io/guess-the-bottle-order/

* 4 bottles are hidden in a secret order (6 colours, no repeats). Crack it in 10 turns.
* ● PERFECT = right colour, right slot. ○ COLOUR ONLY = right colour, wrong slot.
* **1P Solo** or **2P Duo Team** on one device: players take turns, no talking, with a hand-off screen between turns.
* The result card shows the players' names, turns used and the secret code. Share it to Teams, by email, copy the text, or save the card as a PNG.
* Keyboard: `1`–`6` add bottles, `Backspace` removes the last one, `Enter` confirms.

The whole game is one file, [`index.html`](index.html), served by GitHub Pages.
